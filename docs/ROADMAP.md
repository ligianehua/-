# 路线图：卡片之外，俄罗斯跨境电商还需要什么

先泼冷水：**把中文翻成俄语这件事，2026 年已经不值钱了。** 任何一个 LLM 都能翻。
真正让卖家赚钱或亏钱的是下面这些，按"缺了会直接亏钱"到"锦上添花"排序。

## 优先级 P0 · 不做会亏钱

### 1. 定价计算器（Юнит-экономика）
俄罗斯平台的费用结构比亚马逊复杂：佣金按类目、物流按体积重量分档、仓储按天、退货（невыкуп）按件收、还有收单费。
WB 的 SPP（平台补贴折扣）机制意味着"标价"和"到手价"是两个数。

输入：成本（CNY）、汇率、体积重量、类目、目标利润率
输出：三平台各自的建议标价、"цена до скидки"、盈亏平衡签收率（процент выкупа）

一句话：**不算清 unit economics 就上架 = 用真金白银做 A/B 测试。**

### 2. 合规前置检查（在采购前，不是上架前）
现在 Skill 只在卡片阶段提示。应该前移到选品阶段：
- 输入类目 + 商品特征 → 输出：需要哪种 ЕАС 文件、是否 Честный ЗНАК、是否 ФСБ 通报、是否禁运、大致认证成本和周期
- 集成 `честныйзнак.рф` 类目查询和 ТН ВЭД 分类

### 3. 平台 API 直传（MCP Server）
手工把 JSON 粘进后台是浪费人生。三平台都有卖家 API：
- Ozon Seller API：`/v3/product/import`、`/v1/product/import/prices`、`/v1/product/rating-by-sku`
- Wildberries Content API：`/content/v2/cards/upload`、`/content/v2/object/charcs/{subjectId}`（类目属性枚举）
- Яндекс Маркет API：`/campaigns/{id}/offer-mapping-entries`

**做成 MCP 后，Agent 可以先拉类目属性枚举再填卡片，属性名 100% 对得上，而不是靠猜。** 这一步能消掉当前 Skill 里"Тип / Цвет 是枚举、请在后台核对"这类免责声明。

## 优先级 P1 · 决定能不能卖起来

### 4. 关键词接真实数据
现在 `keywords.source = llm-estimate`。要接：
- Яндекс Wordstat API（全网俄语搜索量）
- WB 卖家后台 "Поисковые запросы" 导出
- Ozon "Что ищут покупатели"
- MPStats / Moneyplace API（付费，但有竞品卡片的关键词反查）
接上以后关键词从"合理猜测"变成"带频次的排序"，标题第一个词才敢定。

### 5. 竞品与类目分析
输入类目 → 输出前 20 名卡片的：标题结构、价格带、评分、评论数、主图风格、他们用的属性。
用来回答"这个类目还能不能进""我的标题跟头部差在哪"。数据源同上（MPStats 等）或平台公开页面。

### 6. 评论与问答自动回复（俄语）
俄罗斯买家看评论比看描述认真。差评 24 小时不回，卡片评分掉得很快。
- 输入：评论文本 + 星级 + 订单信息 → 输出：俄语回复（语气规则：不辩解、先道歉、给方案、不留联系方式）
- 问答（Вопросы）：从 FAQ 库自动答，答不了的标出来
- 顺手做 **评论情感聚类**：差评集中在"размер маломерит"就该改尺码表，集中在"пришёл сломанный"就该改包装

### 7. 图文生成闭环
Skill 现在只出图文文案。下一步接图像生成（本环境有 Kling MCP）：
- 主图去背景 + 白底
- 信息图：俄语标题叠加、统一模板、WB 3:4 / Ozon 1:1 自动裁
- 视频：15–30 秒竖版，俄语字幕烧录，TTS 俄语配音
风险：AI 生图的西里尔文字经常拼错，**文字必须后期叠加，不能让模型画字**。

## 优先级 P2 · 规模化以后

### 8. 标签与包装生成
俄语标签（этикетка）现在是文本。要出可打印文件：EAN-13 条码、ЕАС 标志、Data Matrix 位、洗涤图标（服装），PDF 直接给工厂。

### 9. 物流与体积重量
输入包装尺寸 → 体积重量 → 三平台物流分档 → 跨境路线建议（铁路经哈萨克斯坦 / 直邮 / 平台海外仓 FBO）。
和定价计算器打通。

### 10. 广告投放辅助
Ozon「Продвижение в поиске」和 WB「Авторекламa」都靠关键词出价。
从 Skill 的 ВЧ/СЧ/НЧ 直接生成投放词表 + 否定词表 + 分组建议；提醒 ОРД / erid 广告标识义务。

### 11. 促销日历
俄罗斯电商的流量峰值和中国不重合：
Новый год（11 月中–12 月，全年最大）、23 Февраля、8 Марта、1 Сентября（返校）、11.11、Чёрная пятница、平台自己的大促（Ozon「Мегараспродажа」、WB「Всемирный день шопинга」）。
提前 6–8 周提示备货和改卡片。

### 12. 多市场复用（ЕАЭС）
同一份俄语卡片稍改就能上：哈萨克斯坦 Kaspi.kz（俄语 + 哈萨克语双语要求）、白俄罗斯、乌兹别克斯坦 Uzum。
认证 ЕАС 是联盟通用的，一次认证多国可用——这是俄区跨境的隐藏杠杆。

### 13. 本地化 QA
- 术语库（глоссарий）跨 SKU 一致
- 回译抽检（俄→中）看有没有语义漂移
- 让母语者只审"标题 + 前两句 + 图文文案"，其他机器出，省钱

### 14. 卡片效果回流
关键词排名跟踪、点击率、转化率、退货原因 → 自动提出改卡片建议。没有这一环，前面所有优化都是一次性的。

## MCP Server 设计草案

一个 `ru-ecom-mcp` 服务，工具面：

| 工具 | 输入 | 输出 | 数据源 |
|---|---|---|---|
| `marketplace.get_category_attrs` | platform, category | 属性名 + 枚举值 + 必填标记 | Ozon / WB / YM API |
| `marketplace.upload_card` | platform, output.json | 任务 ID / 错误 | 同上 |
| `marketplace.get_card_status` | platform, sku | 审核状态、驳回原因 | 同上 |
| `keywords.search_volume` | words[], platform | 频次、趋势 | Wordstat / MPStats |
| `keywords.autocomplete` | prefix, platform | 联想词 | 平台搜索框 |
| `competitors.top_cards` | category, platform, n | 标题、价格、评分、属性 | MPStats / 公开页 |
| `pricing.unit_economics` | cost_cny, fx, dims, weight, category, platform | 建议价、费用拆分、盈亏点 | 平台费率表（需定期更新） |
| `compliance.check` | category, features | ТР ТС 清单、Честный ЗНАК、禁运 | 本地规则库 + честныйзнак.рф |
| `reviews.list` / `reviews.reply` | platform, sku / review_id, text | 评论 / 发送结果 | 平台 API |
| `label.render` | label_text, ean, dm_code | PDF | 本地渲染 |

实现建议：Python + FastMCP，凭证走环境变量，每个平台一个 adapter。先做 `get_category_attrs` 和 `upload_card`，
这两个立刻消灭最多的手工操作；`pricing` 第二；其余按上面的优先级。

## 不建议做的

- **自动刷评 / 刷单工具。** 三平台都在封，2025 年 WB 直接扣保证金。
- **绕过 Честный ЗНАК。** 海关和平台双重查，货直接扣。
- **一键翻译 100 个 SKU 不看。** 出错成本（驳回、差评、退货）远高于人审前两句的成本。
