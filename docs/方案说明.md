# 俄罗斯跨境电商商品卡片 Skill · 方案说明

> 适用：Codex CLI、Claude Code
> 分支：`claude/russia-ecommerce-product-workflow-o3z5r7`
> 状态：v0.1 已交付，校验通过（0 error）

---

## 1. 一句话

把一份中文产品资料，变成 Ozon / Wildberries / Яндекс Маркет 能直接上架的俄语商品卡片，外加分层关键词、标签、合规检查和自动校验。

不是翻译，是四件事一起做：**本地化 + 平台适配 + 合规 + 搜索优化**。

## 2. 第一性原理

俄罗斯买家在搜索框里打的是俄语口语词，看的是图上的大字，买不买取决于参数是否按俄罗斯习惯写（厘米、公斤、220 В、RU 尺码、逗号小数）。

翻译得再漂亮，标题超过 60 个字符 Wildberries 直接截断；描述里出现 "скидка"，Ozon 直接驳回。所以工作流的每一步都围绕"平台会不会收、买家能不能搜到"来设计，而不是围绕"翻得美不美"。

## 3. 工作流

| 步骤 | 做什么 | 产物 |
|---|---|---|
| 0 归一化 | 单位换成 см / кг / 220 В，小数逗号，千位空格；服装换 RU 尺码；品牌型号保留拉丁 | 标准化参数 |
| 1 看图看视频 | 逐图提取可见卖点，交叉核对参数（图是 USB-C，参数写 Micro-USB 就要指出）；视频拆镜头 | 图片观察记录、视频脚本 + SRT |
| 2 俄语卡片 | 三平台各一个标题，固定结构描述，5–7 条要点，参数表，Ozon / WB 属性映射，6–8 张图文文案，FAQ | `ru.*` |
| 3 关键词 | ВЧ / СЧ / НЧ 三层，强制覆盖转写变体、拉丁原词、错拼、同义词；反向词；Ozon #标签 | `keywords.*` |
| 4 合规 | ТР ТС 法规对照，Честный ЗНАК 判断，可打印俄语标签，广告法红线扫描 | `compliance.*` |
| 5 校验 | `scripts/validate_card.py`，0 error 才交付 | 校验报告 |
| 6 交付 | `output.json` + Markdown 卡片 + 一段说明（类目判断、合规红线、数据来源、待补字段） | 交付包 |

## 4. 输入与输出

**输入**（缺的按 `templates/intake.md` 一次问完）

| 字段 | 必填 |
|---|---|
| 产品名称、品牌、型号 | 是 |
| 产品参数 | 是 |
| 产品介绍 | 是 |
| 图片 / 视频 | 否，有就用 |
| 目标平台 | 否，默认三平台 |
| 类目、售价、认证情况、搜索数据 | 否 |

**输出**：`output.json`，结构见 `templates/output.schema.json`。五个顶层块：`source`、`ru`、`keywords`、`compliance`、`qa`。

## 5. 平台硬限制（校验脚本同步）

| 项目 | Ozon | Wildberries | Яндекс Маркет |
|---|---|---|---|
| 标题 | 200 字符 | **60 字符** | 150 字符 |
| 描述 | 6 000 | **2 000** | 6 000 |
| 图片 | ≤ 15，1:1 | ≤ 30，**3:4** | ≤ 20，1:1 |
| 标题 emoji | 不推荐 | 禁止 | 禁止 |
| 标签 | 描述中 #тег | 无 | 无 |

三平台共同禁止：联系方式、外链、其他平台名、促销词（скидка / акция / хит / лучший / №1）、全大写、未证实的 "оригинал"、医疗功效。

## 6. 校验脚本抓什么

- 各平台标题 / 描述长度
- 禁用词、医疗声明、其他平台名
- 电话、URL、邮箱、社交账号
- emoji（标题报错，正文警告）
- 西里尔占比低于 55%（疑似未翻译）
- 小数点 / 千位逗号 / 英制单位 / 卢布格式
- 标题词根重复（переспам）、品牌名开头
- 关键词去重、标签格式、`keywords.source` 缺失
- 标签文本缺制造商 / 原产国 / 名称

反向测试：一张故意写坏的卡片抓到 11 个 error、8 个 warning。

## 7. 现在的边界

1. **关键词没有搜索量数据。** 没接 Wordstat / WB / Ozon 后台之前，关键词是语言学估计，`keywords.source` 标 `llm-estimate`。
2. **合规是清单，不是法律意见。** 证书类型和 Честный ЗНАК 范围要认证机构确认。
3. **平台字数限制会变。** 常量在 `references/marketplaces.md` 和 `scripts/validate_card.py` 两处，改一处要改另一处。

## 8. 还需要什么功能

翻译本身在 2026 年已经不值钱了。真正让卖家赚钱或亏钱的是下面这些，按"缺了会直接亏钱"排序。

### P0 · 不做会亏钱

| 功能 | 为什么 | 输入 → 输出 |
|---|---|---|
| 定价计算器 | 佣金按类目、物流按体积重量分档、退货按件收、WB 还有平台补贴折扣。不算清 unit economics 就上架，等于拿真金白银做 A/B 测试 | 成本 CNY、汇率、体积重量、类目、目标利润率 → 三平台建议价、"цена до скидки"、盈亏平衡签收率 |
| 合规前置 | 现在只在卡片阶段提示，应前移到选品阶段 | 类目 + 特征 → 需要哪种 ЕАС 文件、是否 Честный ЗНАК、是否 ФСБ 通报、是否禁运、认证成本周期 |
| 平台 API 直传（MCP） | 手工粘 JSON 进后台是浪费人生。先拉类目属性枚举再填卡片，属性名 100% 对上 | Ozon Seller API / WB Content API / Яндекс Маркет API |

### P1 · 决定能不能卖起来

| 功能 | 说明 |
|---|---|
| 关键词接真实数据 | Wordstat、WB "Поисковые запросы"、Ozon "Что ищут покупатели"、MPStats。从"合理猜测"变成"带频次的排序" |
| 竞品与类目分析 | 前 20 名卡片的标题结构、价格带、评分、属性。回答"这个类目还能不能进" |
| 评论与问答自动回复 | 俄语回复规则：不辩解、先道歉、给方案、不留联系方式。顺手做差评聚类 |
| 图文生成闭环 | 主图去背、信息图叠俄语标题、WB 3:4 / Ozon 1:1 自动裁、竖版视频 + 俄语字幕 + TTS。**文字必须后期叠加，AI 画西里尔字会拼错** |

### P2 · 规模化以后

| 功能 | 说明 |
|---|---|
| 标签与包装生成 | EAN-13、ЕАС 标志、Data Matrix 位、洗涤图标，PDF 直接给工厂 |
| 物流与体积重量 | 包装尺寸 → 体积重量 → 物流分档 → 跨境路线（铁路经哈萨克斯坦 / 直邮 / FBO） |
| 广告投放辅助 | 从 ВЧ/СЧ/НЧ 生成投放词表 + 否定词表；提醒 ОРД / erid |
| 促销日历 | Новый год（11 月中到 12 月，全年最大）、23 Февраля、8 Марта、1 Сентября、11.11、Чёрная пятница。提前 6–8 周提示 |
| ЕАЭС 多市场复用 | 同一份卡片稍改上 Kaspi.kz、白俄罗斯、Uzum。ЕАС 认证联盟通用，一次认证多国可用 |
| 本地化 QA | 术语库跨 SKU 一致、回译抽检、母语者只审标题 + 前两句 + 图文 |
| 卡片效果回流 | 关键词排名、点击率、转化率、退货原因 → 改卡片建议。没有这一环，前面所有优化都是一次性的 |

## 9. MCP Server 设计草案

服务名 `ru-ecom-mcp`，Python + FastMCP，凭证走环境变量，每个平台一个 adapter。

| 工具 | 输入 | 输出 | 数据源 |
|---|---|---|---|
| `marketplace.get_category_attrs` | platform, category | 属性名 + 枚举 + 必填标记 | 平台 API |
| `marketplace.upload_card` | platform, output.json | 任务 ID / 错误 | 平台 API |
| `marketplace.get_card_status` | platform, sku | 审核状态、驳回原因 | 平台 API |
| `keywords.search_volume` | words[], platform | 频次、趋势 | Wordstat / MPStats |
| `keywords.autocomplete` | prefix, platform | 联想词 | 平台搜索框 |
| `competitors.top_cards` | category, platform, n | 标题、价格、评分、属性 | MPStats / 公开页 |
| `pricing.unit_economics` | cost, fx, dims, weight, category, platform | 建议价、费用拆分、盈亏点 | 平台费率表 |
| `compliance.check` | category, features | ТР ТС 清单、Честный ЗНАК、禁运 | 本地规则库 |
| `reviews.list` / `reviews.reply` | platform, sku / review_id, text | 评论 / 发送结果 | 平台 API |
| `label.render` | label_text, ean, dm_code | PDF | 本地渲染 |

先做 `get_category_attrs` 和 `upload_card`，消灭的手工操作最多；`pricing` 第二；其余按优先级。

## 10. 不建议做的

- 自动刷评 / 刷单。三平台都在封，WB 直接扣保证金。
- 绕过 Честный ЗНАК。海关和平台双重查，货直接扣。
- 一键翻译 100 个 SKU 不看。出错成本远高于人审前两句的成本。
