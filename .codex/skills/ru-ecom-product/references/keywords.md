# 俄语关键词与标签方法

## 先说实话

LLM 不知道 Wildberries 上个月"пауэрбанк"搜了多少次。没有数据源时你给出的关键词是**语言学上合理的猜测**，
不是搜索量。所以：

- 有数据（Wordstat / WB Jam / Ozon "Что ищут покупатели" / MPStats / Moneyplace 导出）→ 以数据排序，`keywords.source` 写数据来源。
- 没数据 → `keywords.source: "llm-estimate"`，并在回复里明说。用户拿去复核，而不是拿去上架。

## 三层结构（俄语 SEO 术语）

| 层 | 俄语 | 词数 | 作用 | 放哪 |
|---|---|---|---|---|
| 高频 | ВЧ (высокочастотные) | 1–2 | 类目主词，流量大竞争大 | 标题第一位 |
| 中频 | СЧ (среднечастотные) | 2–4，带属性 | 精准流量 | 标题后半、属性、描述首段 |
| 长尾 | НЧ (низкочастотные) | 4+，带场景/人群/问题 | 转化高 | 描述要点、FAQ、图文文案 |

示例（TWS 耳机）：

- ВЧ：`наушники беспроводные`, `tws наушники`
- СЧ：`наушники беспроводные с шумоподавлением`, `наушники bluetooth с микрофоном`
- НЧ：`наушники беспроводные для бега с защитой от пота`, `наушники для айфона с быстрой зарядкой`

## 必须覆盖的变体

1. **转写变体**：`пауэрбанк / повербанк / павербанк / power bank`；`айфон / iphone`；`смарт-часы / смарт часы / смартчасы`
2. **拉丁原词**：品牌、型号、技术名词（`USB-C`, `Bluetooth 5.3`, `TWS`）。俄罗斯买家混合输入很常见。
3. **同义词**：`внешний аккумулятор` 与 `пауэрбанк`；`термос` 与 `термокружка`
4. **错拼与不带 ё**：`черный / чёрный`；`наушники безпроводные`（常见错拼）
5. **格变化**：俄语平台搜索一般做词形归一，不用穷举格；但标题里用主格。
6. **人群/场景修饰**：`для мужчин`, `для женщин`, `для детей`, `для подростков`, `в подарок`, `для дома`, `для дачи`, `для авто`, `для школы`, `для спорта`
7. **节日词**（季节性，放长尾）：`на новый год`, `на 8 марта`, `на 23 февраля`, `к 1 сентября`, `на день рождения`

## 反向词（negative）

放进 `keywords.negative`，理由要写：

- 促销词（平台禁用）：`скидка`, `акция`, `дёшево`, `бесплатно`
- 引流错误人群：卖成人保温杯时排除 `детский`
- 侵权：不是授权经销商别写 `оригинал`、别写竞品品牌名（`как apple`）
- 医疗声明：`лечит`, `лечебный`（非医疗器械）

## 标签（hashtags）

- 只有 Ozon 描述里 `#тег` 有效，WB / Яндекс 没有标签概念。
- ≤ 10 个，全小写，无空格（`#пауэрбанк20000`），西里尔为主。
- 内容 = ВЧ + СЧ 的压缩版，不要放品牌以外的拉丁词。

## 放置规则（避免"переспам"）

- 标题：1 个 ВЧ + 1–2 个 СЧ，自然语序，不重复词根。
- 描述：每个关键词最多出现 2 次；总关键词密度 ≤ 5%。
- 属性字段（Тип / Цвет / Материал / Назначение）是 WB 最重的搜索权重，**必须填满**，比描述堆词有效十倍。
- 图文文案里的词平台不索引，只影响转化，写给人看。

## 数据源清单（有条件时接入）

| 来源 | 类型 | 说明 |
|---|---|---|
| Яндекс Wordstat | 免费 | 全网俄语搜索量，看词形和季节曲线 |
| WB Jam / "Аналитика продавца → Поисковые запросы" | 卖家后台 | WB 站内真实搜索词 |
| Ozon Seller → "Что ищут покупатели" | 卖家后台 | Ozon 站内搜索词、缺货品类 |
| MPStats, Moneyplace, Маяк, Shopstat | 付费 SaaS | 竞品卡片关键词、销量估算 |
| 平台搜索框联想（autocomplete） | 免费 | 最快的长尾词来源 |

接入方式见 `docs/ROADMAP.md` 中的 MCP 设计。
