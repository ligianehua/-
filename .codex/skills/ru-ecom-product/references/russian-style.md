# 俄语商品文案风格与书写规范

## 语气

- 用 `вы`（小写）对买家说话，不要用 `ты`。商品描述属大众传播，`Вы` 大写显得像公文。
- 句子短。俄语买家浏览描述平均不到 10 秒，前两句必须说清"这是什么、解决什么问题"。
- 名词开头的要点句（`Ёмкость 20000 мАч — хватит на 4 полные зарядки смартфона`），不要每条都以动词开头。
- 少用感叹号。一个卡片最多一处。
- 不要直译中文营销腔："匠心""极致""尊享"在俄语里没有对应，硬翻会变成 `мастерство души` 这种笑话。用具体数据代替形容词。
- 不用 `качественный`（"高质量的"），这是俄语电商里最空的词。写材料、写测试、写保修。

## 描述结构（固定）

```
[1–2 句：场景 + 痛点 + 产品是什么]

Преимущества:
• …（5–7 条，名词开头）

Характеристики:
• Материал: …
• Размеры: …
• Вес: …

Комплектация:
• …

Гарантия и уход:
• Гарантия 12 месяцев.
• … 
```

Ozon 支持 rich-content 时，把 `Преимущества` 每条变成一个图文块。

## 数字与单位

| 项目 | 写法 | 错误示例 |
|---|---|---|
| 小数 | `1,5 кг`（逗号） | `1.5 кг` |
| 千位 | `20 000 мАч`（空格）；标题里可写 `20000` 省字符 | `20,000` |
| 长度 | `см`, `мм`, `м` | `cm`, `inch` |
| 重量 | `г`, `кг` | `g`, `lbs` |
| 容量 | `мл`, `л` | `ml` |
| 电 | `220 В`, `50 Гц`, `22,5 Вт`, `20000 мАч`, `USB-C` | `220V`, `20000mAh` |
| 温度 | `°C` | `°F` |
| 货币 | `1 990 ₽`（空格 + ₽ 在后） | `₽1990`, `1990 руб.` 在卡片里可接受但不统一 |
| 日期 | `ДД.ММ.ГГГГ` | `MM/DD/YYYY` |
| 数字与单位之间 | 不换行空格 | 紧贴 |

英寸必须换算成厘米（1 дюйм = 2,54 см），屏幕尺寸例外可写 `6,7"`。

## 尺码换算（服装）

女装：

| 国际 | RU | 胸围 см |
|---|---|---|
| XS | 42 | 84 |
| S | 44 | 88 |
| M | 46 | 92 |
| L | 48 | 96 |
| XL | 50 | 100 |
| XXL | 52 | 104 |
| 3XL | 54 | 108 |

男装：

| 国际 | RU | 胸围 см |
|---|---|---|
| S | 46 | 92 |
| M | 48 | 96 |
| L | 50 | 100 |
| XL | 52 | 104 |
| XXL | 54 | 108 |
| 3XL | 56 | 112 |

鞋：RU 码 = EU 码（俄罗斯实际使用欧码），成人 36–46。中国码（如 250）换算：脚长 mm。
**必须在描述里附"Размерная сетка"（尺码表）和 `Замерьте стопу / обхват груди` 的提示**，这是 WB 服装退货率的最大变量。

童装按身高（`рост`）标：`рост 110–116 см`。

## 电器类必写

- 电压 `220 В / 50 Гц`，插头类型 `евровилка (тип C/F)`。如果是美标或英标插头必须写明 `в комплекте переходник`。
- 功率 `Вт`，能效（如适用）。
- 是否需要 ЕАС 认证见 `compliance.md`。

## 颜色词（平台枚举常用）

`чёрный, белый, серый, серебристый, красный, синий, голубой, зелёный, жёлтый, оранжевый, розовый, фиолетовый, бежевый, коричневый, золотой, бирюзовый, хаки, бордовый, прозрачный, разноцветный`

Ozon 和 WB 颜色字段是枚举，用上面的基础色；具体色调写在标题或描述里（`тёмно-синий`, `графит`）。

## 常见翻译坑

| 中文 | 错误直译 | 应写 |
|---|---|---|
| 充电宝 | зарядное устройство | внешний аккумулятор（正式）/ пауэрбанк（口语，搜索量大） |
| 数据线 | линия данных | кабель USB-C / кабель для зарядки |
| 保温杯 | термочашка | термос / термокружка |
| 收纳盒 | коробка для хранения | органайзер / контейнер для хранения |
| 手机壳 | корпус телефона | чехол для телефона |
| 无线耳机 | беспроводные уши | беспроводные наушники / TWS-наушники |
| 一件代发 | — | дропшиппинг |
| 尺码偏小 | размер маленький | маломерит（俄语电商专用词；偏大 = большемерит） |
| 男女同款 | — | унисекс |
| 新款 | новая модель | новинка（但不要放标题堆词） |
| 包邮 | — | 不写，平台统一物流 |

更多见 `glossary.md`。

## 字母 ё

用 `ё` 还是 `е`：平台搜索都能匹配，但正文里统一。建议正文用 `ё`（`чёрный`），关键词列表里两种都列。
