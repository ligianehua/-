# 俄罗斯 / 欧亚经济联盟（ЕАЭС）合规速查

> 这是产品卡片层面的合规检查清单，不是法律意见。涉及证书的，让用户找认证机构（орган по сертификации）确认。

## 1. ЕАС 认证：сертификат / декларация / отказное письмо

欧亚经济联盟技术法规（ТР ТС / ТР ЕАЭС）覆盖的商品，必须有对应文件才能上架。三平台都会在类目里要求上传。

| 文件 | 适用 | 谁出 |
|---|---|---|
| Сертификат соответствия | 高风险品类（儿童、低压电器、玩具、个人防护） | 认可的认证机构，需送样测试 |
| Декларация соответствия | 中风险（大部分家电、纺织、化妆品） | 申请人自我声明 + 检测报告，登记后生效 |
| Отказное письмо | 不在任何 ТР 范围内的商品（手机壳、装饰品、部分文具） | 认证机构出具的"无需认证"信函 |

常用技术法规对照：

| 法规 | 名称 | 覆盖 |
|---|---|---|
| ТР ТС 004/2011 | О безопасности низковольтного оборудования | 50–1000 В 电器：充电器、小家电、灯具 |
| ТР ТС 020/2011 | Электромагнитная совместимость | 几乎所有带电子的产品，与 004 一起办 |
| ТР ЕАЭС 037/2016 | Ограничение применения опасных веществ (RoHS) | 电子电器 |
| ТР ТС 017/2011 | О безопасности продукции лёгкой промышленности | 成人服装、鞋、纺织、皮具 |
| ТР ТС 007/2011 | О безопасности продукции для детей и подростков | 童装、童鞋、婴儿用品 |
| ТР ТС 008/2011 | О безопасности игрушек | 玩具 |
| ТР ТС 009/2011 | О безопасности парфюмерно-косметической продукции | 化妆品、香水 |
| ТР ТС 005/2011 | О безопасности упаковки | 包装、食品接触容器 |
| ТР ТС 010/2011 | О безопасности машин и оборудования | 电动工具、机械 |
| ТР ТС 019/2011 | Средства индивидуальной защиты | 口罩、手套、护具 |
| ТР ТС 021/2011 | О безопасности пищевой продукции | 食品 |
| ТР ЕАЭС 044/2017 | Питьевая вода | 瓶装水 |

电子产品还可能涉及 ФСБ нотификация（含加密功能的设备：蓝牙、Wi-Fi），进口环节需要。

**在输出里怎么写**：`compliance.tr_ts` 列出适用法规编号 + 文件类型；不确定就写 `требует уточнения у органа по сертификации`。

## 2. Честный ЗНАК（强制商品标识）

俄罗斯国家追溯系统，Data Matrix 码贴在每件商品上。跨境卖家通常通过平台或代理商申请码。
强制类目（2025–2026 已生效，持续扩展）：

- 服装（大部分品类，包括针织、外套、衬衫、裤装、运动服）、鞋类
- 香水与化妆品（部分）
- 轮胎、相机与闪光灯、自行车
- 乳制品、瓶装水、啤酒与低度酒、软饮
- 医疗器械（部分）、膳食补充剂（БАД）、抗菌剂
- 纺织（床品、毛巾、桌布）
- 儿童玩具（分阶段）、电子烟

不确定的类目：写 `проверить на честныйзнак.рф`。
输出字段：`compliance.chestny_znak: true | false | "check"`。

## 3. 俄语标签（этикетка / маркировка）

《消费者权益保护法》（ЗоЗПП）与 ТР ТС 要求商品上必须有俄语信息。跨境商品在中国出厂时贴好最省事。最低内容：

```
Наименование товара: …
Модель / артикул: …
Состав / материал: …
Изготовитель: [公司名, 地址, 国家]
Импортёр / уполномоченное лицо в ЕАЭС: …（跨境 FBO 由平台承担，DBS 需自填）
Страна происхождения: Китай
Дата изготовления: ММ.ГГГГ
Срок службы / срок годности: …
Условия хранения / эксплуатации: …
Знак ЕАС（如适用）
Штрихкод EAN-13
Код Data Matrix Честный ЗНАК（如适用）
```

服装额外：尺码（RU）、洗涤标识（ГОСТ ISO 3758 图标）。
电器额外：额定电压/功率、安全警告。

输出字段：`compliance.label_text`，直接可打印。

## 4. 广告法与文案红线（ФЗ «О рекламе»，ЗоЗПП）

| 风险 | 例子 | 处理 |
|---|---|---|
| 最高级/绝对化没有证据 | `лучший`, `самый`, `№1`, `единственный` | 删除，或改为具体数据 |
| 医疗功效 | `лечит`, `от боли`, `укрепляет иммунитет` | 非医疗器械/药品一律删 |
| "оригинал" 声明 | `100% оригинал` | 只有品牌授权才能写；否则写 `совместимый` |
| 对比竞品 | `лучше чем Apple` | 删 |
| 未证实的认证 | `сертифицировано в РФ` 但没证书 | 删 |
| 外文未翻译 | 整段英文卖点 | 全部俄语，品牌与型号例外 |
| 儿童商品年龄标 | 缺 `0+ / 3+ / 6+` | 玩具必须标龄 |

如果做站内广告（Ozon Продвижение、WB Реклама），2023 年起广告需在 ОРД 登记并带 `erid` 标识——那是广告投放层面，不在卡片里，但要提醒用户。

## 5. 禁运与限制（跨境）

以下类目跨境直发基本做不了或需要特别许可，遇到就在 `compliance.warnings` 里直接警告：

- 药品、处方类、含麻醉成分
- 武器、刀具（刃长限制）、军品外观
- 无线电设备超功率、干扰器
- 酒精、烟草、电子烟（跨境禁）
- 活体动植物、种子
- 药用植物制品、部分 БАД
- 车辆零部件中的安全件（气囊、刹车）需 ТР ТС 018

## 6. 退换货与保修（写进描述）

- 远程销售：买家收货后 7 天内可无理由退（ЗоЗПП ст. 26.1）；平台通常给到 14–21 天，按平台政策写。
- 不可退类目：内衣、泳衣、个人卫生用品、部分化妆品——描述里可以写 `не подлежит возврату согласно ПП РФ № 2463`。
- 保修：写明期限 `Гарантия 12 месяцев` 与承担方（платформа / продавец）。
