# 追问模板

## A. 向用户追问（缺资料时一次问完）

只问缺的，不要全问。按用户语言输出。

```
为了产出可上架的俄语卡片，还需要补充：

1. 产品参数（缺 ___）：尺寸（长×宽×高，厘米）、重量（净重 + 含包装）、包装尺寸、材质、颜色、功率/容量、包装清单
2. 销售模式：跨境直发，还是俄罗斯本地仓（FBO / FBS / DBS）？影响费用、进口人、标签
3. 类目：这是 ___ 吗？还是 ___？（影响字段和认证）
4. 变体：有几个颜色 / 容量 / 尺码？每个变体的 SKU 和对应图片
5. 品牌：有注册品牌吗？没有就按 "Нет бренда" 处理
6. 目标平台：Ozon / Wildberries / Яндекс Маркет，全出还是只出某个？
7. 认证：手里有 ЕАС 证书或 отказное письмо 吗？（没有我会在合规段落标出需要哪种）
8. 图片：能给图片文件或 URL 吗？没有的话，口述一下每张图的内容
9. 价格：目标售价（卢布）或成本（人民币）？用于定价提示，可跳过
10. 搜索数据：有 Wordstat / WB 搜索词导出吗？没有我会把关键词标为候选
```

1、2 是硬需求，其余缺了就在输出里标 `уточняется`，不要因此停下。

## B. 向供应商补资料（`qa.supplier_request_zh`）

资料缺口通常在供应商那边，不在用户那边。把 `facts` 里 `missing` 和 `conflict` 的条目整理成一段**可以直接转发**的中文，不是错误代码。

模板：

```
您好，我们在为 [产品名 / 型号] 制作俄罗斯平台上架资料，需要请您确认以下信息：

【缺失】
- 商品净重、含包装重量（克）
- 包装尺寸（长 × 宽 × 高，厘米）
- 制造商名称、地址（用于俄语标签）
- 是否附带 [配件名]

【需要核对】
- 参数表写容量 500 mL，产品图上印的是 450 mL，请确认实际值
- 介绍写"不锈钢"，请确认具体牌号（如 304 / 316），没有的话我们只写"不锈钢"

【如有请提供】
- 参数表原件或包装照片
- 已有的检测报告 / ЕАС 证书 / 拒绝函

谢谢。
```

规则：
- 每条对应一个 `facts[]` 条目，不多问。
- 冲突项把两个值和各自来源都写出来，让供应商选，不替他选。
- 不问用户已经回答过的。
