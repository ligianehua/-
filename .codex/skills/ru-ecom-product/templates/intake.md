# 追问模板（缺资料时一次问完）

只问缺的，不要全问。按用户语言输出。

```
为了产出可上架的俄语卡片，还需要补充：

1. 产品参数（缺 ___）：尺寸（长×宽×高，厘米）、重量（含包装）、材质、颜色、功率/容量、包装清单
2. 类目：这是 ___ 吗？还是 ___？（影响字段和认证）
3. 品牌：有注册品牌吗？没有就按 "Нет бренда" 处理
4. 目标平台：Ozon / Wildberries / Яндекс Маркет，全出还是只出某个？
5. 认证：手里有 ЕАС 证书或 отказное письмо 吗？（没有我会在合规段落标出需要哪种）
6. 图片：能给图片文件或 URL 吗？没有的话，口述一下每张图的内容（颜色、角度、配件）
7. 价格：目标售价（卢布）或成本（人民币）？用于定价提示，可跳过
8. 搜索数据：有 Wordstat / WB 搜索词导出吗？没有我会标注关键词为估算
```

不要因为缺 5–8 项而停下。1–2 是硬需求，其余缺了就在输出里标 `уточняется`。
